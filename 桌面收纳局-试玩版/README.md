# 桌面收纳局

一个原创的桌面主题三消小游戏：在凌乱的书桌上，连续点选三个相同的物品，把它们收纳归位。

## 玩法

- 点击桌面上的物品，将它放入底部的临时收纳格。
- 凑齐三个相同物品后会自动消除。
- 收纳格只有 7 个位置，塞满就会失败。
- 在 150 秒内清空桌面即可通关。

## 道具

- **撤回**：撤回最近一次选择。
- **打乱**：重新分散桌面上的物品。
- **吸尘**：直接清除一组相同物品。

## 本地运行

直接用浏览器打开 `index.html` 即可运行，无需安装依赖或构建。

## 技术栈

原生 HTML、CSS、JavaScript；支持桌面端和移动端浏览器。
